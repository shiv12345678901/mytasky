# UI and UX review checklist

- [ ] The screen has one clear user job and primary action.
- [ ] Content hierarchy is understandable without relying on color.
- [ ] Touch targets are at least 44×44 CSS pixels.
- [ ] Labels describe actions and icon-only controls have accessible names.
- [ ] Keyboard focus is visible and reading order follows visual order.
- [ ] Light and dark themes meet contrast expectations.
- [ ] Safe areas, 320px width, long labels, and empty data are handled.
- [ ] Loading, success, error, offline, and retry behavior are intentional.
- [ ] Returning navigation restores the correct parent and scroll position without flashing.
- [ ] Animation is stable, brief, and removed appropriately for reduced motion.
- [ ] Sheets use opaque surfaces and provide gesture plus explicit dismissal.
- [ ] Tests and verification commands pass.
